# 首次安装后的配置检查表

本页是**检查顺序**，不是对任何具体版本菜单位置的承诺。不同镜像版本和启用模块的菜单可能不同；以实际管理后台及 API 为准。

## 1. 验证部署

- [ ] 记录镜像版本与 digest、部署目录、备份位置，确认服务健康。
- [ ] 使用管理员账户登录；安全保存管理员入口与凭据。动态 `secure_path` **不是身份认证**。
- [ ] 验证公网 HTTPS、`APP_URL`、安全 Cookie 和可信反向代理范围，不开放调试模式。
- [ ] 检查邮件发送能力；密码重置与邮件验证链接依赖正确的公网 `APP_URL`。
- [ ] 做一次备份并在隔离环境验证恢复；不要把备份、密钥或日志提交至 Git 仓库。

## 2. 配置业务

- [ ] 核对基础站点设置、用户注册和验证码策略。
- [ ] 创建测试套餐并验证显示、订阅与订单状态。
- [ ] 如使用支付功能，先用**测试商户和测试用户**验证回调签名、订单幂等与金额对账；不可在生产账户上进行破坏性测试。
- [ ] 验证普通用户不能使用管理员、Node 或 Agent 的凭据访问受保护接口。

## 3. 接入节点和扩展

- [ ] 阅读 [节点管理指南](../guides/node-management.md)，只按对应协议配置 TX-Node。
- [ ] 插件和主题在预发环境先验证来源、包约束、升级和停用行为；PHP 插件不是沙箱。
- [ ] 按需启用 MCP/Agent Ops；检查 ability、target scope、审批与审计，默认不授予高风险权限。

## 4. 上线之前

按 [完整发布验收 Runbook](../operations/release-staging-acceptance.md) 完成隔离环境的数据库恢复、真实 HTTPS/反代、支付沙盒、Node/Agent 及故障恢复验证。CI 和页面能打开都不能取代这一步。
