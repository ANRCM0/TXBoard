## 原生契约与证据

当前统一契约 223 项。服务器/节点、仪表盘、模板、插件/主题、重置历史、订阅条款、资金调整、个人政策和用量修正均由实际 owner 实现，契约与 SDK 已生成。新增 migration 的列、主键、唯一约束、索引和外键纳入 Runtime Readiness。

个人折扣和推荐人佣金政策被后续订单的不可变快照实际消费；首次付费资格绑定成功资金分配。已结算用量修正保留原始观测、追加独立证据并校验记录/周期修订，未通过直接改计数代替所有者流程。钱包和佣金调整使用独立 contra 与 journal，既有订单和奖励不被追溯改写。

邀请关系保留原生不可变语义；手机号没有验证/规范化/唯一性所有者时不提供任意写入。角色授予不混入普通账户资料。上述边界已在页面说明和原生流程中体现。

本轮早期已运行的定向 PHP、前端、节点和浏览器检查仅保留为诊断历史；它们不是当前源码或本轮功能验收。最终功能检查统一移到 Actions，按实际候选 SHA 记录，不沿用旧绿灯。

本轮统一静态项通过：223 项生成契约一致性、Core/Kernel/浏览器边界、169 项管理员操作入口、前端所有权、CI 策略、文档链接、Renderer 注册表、149 个变更 PHP/脚本文件语法、全 workspace 类型与前端生产构建。最终 PHP 修改另经语法检查。静态提取覆盖 133 个文件、2227 个中文源键；英俄资源各 2465 项，缺失键、原始中文 JSX、占位符差异及新增 Feature 测试的 MySQL 选择遗漏均为 0。
