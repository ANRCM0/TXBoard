# Native Machine and Workerman control closure v1 (Candidate)

Core and Node use their existing same-origin native HTTP/WSS credentials and path. The shared Machine socket multiplexes distinct node IDs; a node-scoped change or removal must not revoke a still-authorized sibling. A completed exact native401 Machine denial remains terminal for the orchestrator. A successful authenticated machine/nodes response removing a previously running child is a distinct membership withdrawal, not a fabricated HTTP404; its fixed cancellation cause must stop that child and preserve terminal traffic. Ordinary transport cancellation is not itself an authority denial.

Core freezes each Server created/updated/deleted event before a deferred commit callback reads original/changes. Old and new Machine IDs, relevant config/group/enable changes and node ID stay bound to that event, including repeated saves; actual rollback emits no push. Current desired membership is always queried under current Machine identity. Token rotation retains the existing sensitive response and is observed by current authentication; no long-lived initialized worker may resurrect old credentials.

Registry replacement installs the successor before closing the old standalone or machine socket, so stale onClose cannot clear the successor's online/device facts. Reassigning one node away from a shared Machine socket detaches only that mapping, retaining sibling and Machine connection. Removed membership clears only that old node's online/device state and emits the current machine list; newly attached nodes get current config/users. Registry transitions do not confer permission: native per-node HTTP/frame auth still rechecks enabled ownership. Reconciliation must not close a shared Machine socket solely because one former member is disabled or removed.

A native membership-withdrawal cause reaches the child Service's stop/checkpoint path. It closes listener/established streams and records new unreported cumulative delta in its independent terminal slot without attempting delivery using unavailable node scope. Machine denial propagates a bounded signal to the main loop, cancels/join all services/shared WS and returns a typed cause; no child waits on itself. A restart with current valid Machine credentials drains original pending/terminal IDs before reopening the corresponding listener, while old credentials never open listeners.

Acceptance uses a fresh dedicated synthetic MySQL/Redis database and true PHP Workerman process behind a same-origin trusted TLS HTTP/WSS proxy. Real administrator login and registered node/machine endpoints create or mutate state; real Orchestrator plus ordinary sing-box VLESS/VMess nodes carry actual TCP traffic. Verify initial two-node credential scope and full sync; target-only config apply; one disabled node closes while sibling stream continues; online/device facts reflect only removed scope; reenable freshly authenticates; actual Machine token rotation yields native401 and stops both listeners/connections while retaining distinct traffic; rejected old-token restart and authenticated new-token replay; replacement sockets do not clear successor; ordinary network/5xx/disconnect retries. Do not shorten production timers secretly, treat Redis publish as Node application, or claim scripts/model mocks are Workerman evidence.

Current single-node snapshots, kernel application, immutable reporting, Usage-v2 isolated boundaries and full PHP/Node race/vet/build gates remain required. Finite offline leases, production PKI, all-protocol/Cluster/HA, global producer/queue drain and production authority switch remain separate unfinished requirements.

Redis per-node publications identify a changed domain; Workerman rechecks current token/active membership and reconstructs config/users/device snapshots from Core before sending. A combined group/config/machine reassignment cannot deliver newly authorized credentials to the former machine. Queued old user removes become current complete user snapshots, so later regrant/reset is not overwritten. Unknown events are dropped. Machine replacement installs all current node mappings before old socket close, preserves device facts for the membership intersection, and isolates logged cache-cleanup failures from mandatory registry transition and close. Empty device dictionaries serialize as JSON objects.
