# Isolated native cancellation integration

Run `bash scripts/tests/internal-order-cancel/run.sh "$PWD/api"` in CI after locked dependencies and Gateway build. Requires exclusively owned `txboard_order_cancel_test`, refuses non-testing/nonempty fixtures. Tests the real Core mTLS operation through Gateway fixed client, actual SDK route and SDK. Order creation reserves wallet/coupon, cancellation restores once. Current ownership/ban/role/revocation, closed body/query, post-commit false and audit503 semantics, one-attempt SDK and fixed diagnostics are checked. The test-only router uses fixed private fixture file modes for synthetic hooks; HTTP input cannot select them. PKI/credentials/config private material is removed after execution; sanitized receipt remains. These isolated Internal API checks do not establish production availability.
