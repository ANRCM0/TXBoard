## 本轮明确采用的产品规则

### 升级折抵属于内核，不属于支付插件

候选从已锁定订阅及不可变已履约购买建立来源报价。有限期来源使用真实 UTC 覆盖秒数，各来源的现金/carry 分量分别向下取整；永久套餐使用已结算与持久预留用量后的剩余额度，重置不恢复旧购买的可抵扣值。现金来源先扣已验证退款及其他保留/已消费 claim；carry 独立记录，不变成钱包可退现金。抵扣不超过目标原价，超额不铸造钱包余额。

所有 native upgrade（包括抵扣额为零）持久化不可变 quote、来源购买 hash、订阅版本和当前周期指纹。报价不超过两小时，也不能跨过来源到期或当前周期边界；永久下单键返回原订单/报价，不能重试重新计价。付款前重验来源、财务证据和有效期。取消释放现金 claim 而不删除 quote；真实迟到渠道收款保留为退款负债。接受付款或净零免费结账、SQL 订阅替换及操作回执同事务完成，后续 durable work 处理提交后的凭据同步与重放。

这些是本批实现与验收目标，尚未取得新提交的 CI 通过证据，不能将设计或旧头绿灯写成已验证结果。完整契约见 [Native upgrade credit v1](../../../contracts/v2/native-upgrade-credit-v1.md)。

### 退款仅是钱包资金操作

全额和部分退款都保持 `entitlement_effect=none`、`subscription_id=null`。无论新购、续费、换套餐、重置或是否已履约，退款本身不取消订单/任何待执行、执行中或已完成 work，不撤销订阅，不重建旧条款，不移动或删除用量，也不触发凭据失效。需要关闭访问时由管理员另走有独立授权的生命周期操作。

可退款现金受原来源、跨混合份额累计退款及升级 claim 共同限制。已转移的非现金抵扣不能退成钱包余额。不要求原路退款或历史权益精准逆转；它们不是本轮成熟度阻塞项。资金来源、幂等、预算与并发安全仍是必须验收的内核行为，不能因取消精准退款而降低检查。

### 插件面向统一当前契约

新插件使用显式 `package.schema=1`、`payment.contract/provider/snapshot_schema` 和唯一 typed PHP 接口；管理名单/表单与结账共用验证后的注册表。没有旧接口兼容层，旧包和旧直接执行入口明确拒绝；可用随包支付实现为 EPay，新插件可从 fail-closed starter 开发。

有历史 dispatch 的插件永久保留原 verifier 与冻结配置，managed 升级、上传替换、卸载和删除拒绝；停用仍允许受限原交易验证与查询。没有 dispatch 的包可按当前包流程维护，worker 需按版本规则重启。永久 pin 是明确维护限制与资金证据安全策略，不是要求建设旧插件兼容、多版本代码仓库或版本交接。可信进程内 PHP 不等于安全沙箱。见[支付插件开发指南](../../development/payment-plugin-development.md)。

## 仍须关闭的完成缺口

### 1. 本批精确提交验收

本地只进行轻量差异/静态检查，不安装 PHP/vendor/node_modules 或搭建数据库。升级折抵、零额/零抵扣来源指纹、退款不影响权益/work、来源预算与 claim、插件统一及真实回调的行为和 MySQL 竞态由 GitHub Actions 集中验收。

关闭条件：冻结新提交，运行本批实际相关检查并修复失败；旧 `e9e65f2`、未触发、跳过或同名空任务不能算新候选验收。随后核对依赖及至少一名非作者领域审阅。通过 CI 不自动授权合并或发布。

### 2. 正式接口覆盖与审计规范

当前服务 registry 仅开放已列出的固定操作，不自动开放所有 Laravel 管理路由或管理员浏览器通道。账户/网络管理的完整写操作、完整嵌套输出 schema 仍需按真实消费者补齐；旧 `plan_id/period` 不能冒充 native `offer_id`。

边界审计已有 service/epoch/actor/operation/domain/request/execution/status/time，拒绝、未知与成功分开。安全 resource target、risk/protocol 及 domain receipt-key 关联尚未全部收口。全局安装/包加载/body-size 拒绝、路由不匹配和 ingress 429 在逐条服务操作 SQL audit 之外，不能说所有 HTTP 拒绝都已审计。

### 3. 生产 PKI 与信任分发

生产反向代理必须验证实际客户端证书，清除用户伪造验证头，保护到 Core 的下游 TLS，并验证 SAN/EKU/撤销与轮换。ingress 预算按真实 socket 来源限流，生产需共享原子缓存和边缘 ACL。Provider/Node 信任分发及真实证书轮换还需物理部署证据；同宿主 hosted CI 或单测夹具不能代替。

### 4. C5 基础交付

新安装、正常版本更新、必要恢复、固定镜像/版本组合和对应运维说明仍未交付。必须复用独立 Deploy 的职责，不能用 Core 候选代码、数据库模型或镜像构建通过替代安装更新验收。
