# 隔离管理客户端联调

`run.sh <Core api>` 只在预先列举的专用合成 MySQL 库迁移和初始化，不重置已有数据。先构建 `gateway/` 的锁定 TypeScript 代码，再运行真实管理客户端→TLS1.3 mTLS→Core→MySQL链路。无需公开Gateway管理路由、Redis业务状态或浏览器密钥。

10项验收涵盖独立管理证书/生产拒绝、原生登录、当前身份、精确大整数仪表盘、普通User/staff拒绝、额外身份输入、封禁/降权、错误路径、真实审计故障隐藏会话和最终撤销。凭据只在进程内存中；EXIT trap 清理密钥、私有配置和actors文件，仅保存脱敏receipt和固定进程日志。该测试不代表SC-v2、生产PKI或完整管理前端已完成。
