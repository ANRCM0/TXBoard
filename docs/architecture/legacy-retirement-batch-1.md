## 现行依赖与本批保留

- `/api/v1`：忘记密码、邮件验证码/魔法链接/Telegram、用户设置、礼品卡、返佣提现、流量日志、订阅及部分订单详情；新支付回调出站开关默认关闭。
- `/api/v2`：React Admin 登录/动态 `secure_path`、Agent、机器与 Node 历史 HTTP 等。
- 独立订阅链接 `/{subscribe_path}/{token}` 仍通过 V1 ClientController 生成 Clash/Sing-box 等配置；与 TX-Node 控制协议不能混淆。
- `xboard_auth_data` 是浏览器本地一次性令牌迁移能力，生产客户端覆盖率确认前不得删除。
- `/txapi/node/v1/*` 服务端已落地，TX-Node 尚未适配/端到端验收；原生 WS 默认关闭，旧 WS 保留。
- Module、Plugin、Theme、Agent 领域及 `v2_*` 表不得因目录或历史名称而删除。

## 独立 PR 与回滚

- LR-01 纯文档，无运行时变动，可单独回滚。
- LR-02 仅更新 Vue 业务客户端和回归测试；不修改 Laravel 旧路由、账本或数据库，回滚前端即可恢复旧轮询/会话调用。
- LR-03 限于页面显示适配与单元测试；若展示异常回退该 PR，不改变原生 API 契约。
