# 前端延期与 Agent/MCP 退役

2026-10-13 用户最新决定：管理前端与用户前端都暂缓，后续新增前端开发集中到独立 `TX-F` 项目，该目录只本地提交、不推送；当前只建立仓库与范围文档，不启动前端实现。当前 TXBoard（后续 tx-core）仅推进 Core、Gateway 和 Node；安装器独立由 TXBoard-Deploy 承担。现有 Admin/User UI 和主题仍是当前消费者，其构建依赖在替代入口验收前继续保留。AgentOps/MCP 直接清理，取消原先的插件拆分交付；需要时另立契约重新开发。

Core 保持账户、订阅、资金、权限、审计和节点控制的唯一权威。后续独立前端接入仍须验证服务身份、实际 actor、RBAC、审计及安全通道，当前 Gateway 不开放管理员入口。延期两个新前端不放宽当前身份、数据及计费正确性要求；旧版本兼容不是当前开发承诺。

退役删除 Agent HTTP/Admin API、配对和公开接入指南、巡检任务、Module 内置适配器、管理页面及其请求、MCP 工具/进程/构建/CI。旧 `agent:` Token 名称或作用域不能再通过 Sanctum 认证，不能转换成普通 User/Admin 凭据。历史 Token、Agent 审计与动作表及迁移保留，不由本次升级删表、改写历史或执行旧审批。

镜像不再内置 MCP 或其 Node.js 运行依赖；`/mcp` 和子路径在边缘返回404。安装器移除启用开关与管理菜单；旧环境变量不再启动功能。Node 的正常用户/配置同步、用量上报、Machine 安装器更新仍属基础业务，与 AI Agent 功能分别验证。

本页是 Agent/MCP 退役规则的统一入口，不再保留分散的接入指南或重复占位契约。原说明可从 Git 历史查询；删除旧文档不删除历史 Token、数据库迁移、审计记录或验收证据，也不恢复旧接口。

当前工作按[Native 开发与数据基线](../../development/native-development-baseline.md)及真实接口推进；历史库存/验证 JSON 保留当时路径与哈希，不是当前接口清单。
