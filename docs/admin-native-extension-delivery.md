# 原生插件与主题管理

日期：2026-10-21。本文记录源码和针对验证；未提交、未发布，未对实际部署环境执行安装、启停、升级或删除。

## 所有者链

- 插件卡片、配置、生命周期和运行入口通过 `NativeModuleAdminController` 的固定 Core 绑定进入 `NativeModuleAdministration` / `NativeModulePresentation`。
- 插件安装、启停、升级、配置和卸载仍由 `ModuleDeployment` 所有；新增原生入口在原包指纹、读取修订和当前管理员授权下入场，原请求回执恢复继续复用同一持久意图。
- 运行入口只允许包声明的管理员 operation；读取与 domain 写入分别进入现有 `ExtensionController`。后台提供声明操作控制台，运行结果递归移除敏感字段、引用与实际宿主秘密值。后台不加载包内任意脚本。
- 主题配置仍由 `ThemeService` / `ThemeV2Runtime` 所有，配置读取主库当前值，以安装身份绑定的 HMAC 修订执行 CAS，并在同一事务写入原请求回执。
- 主题候选部署和生命周期由 `NativeThemeDeployment` 持久意图包围现有静态主题 owner。准备意图提交后，再持有全局运行锁、当前授权和设置写锁执行真实操作；恢复时确认目标效果或严格匹配原状态，无法匹配时返回待人工恢复错误。

## 管理页能力

插件默认显示功能分类，可切换支付、其他和全部。卡片展示真实版本、来源、健康、受保护和升级状态；仅呈现当前权限与所有者支持的动作。文档按纯文本显示，配置有本地编辑器、草稿关闭确认、修订冲突与凭据保留说明。

秘密引用只有部署策略明确授权的安装身份、模块、字段、管理员与引用组合才能替换。界面不返回原引用和秘密值。未声明引用槽的敏感字段被隐藏并原样保留；包含嵌套敏感字段的公开 JSON 编辑不予开放，避免省略字段变成秘密删除。

主题卡片可保存已声明公开配置、应用未使用主题，以及删除非当前、非内置主题。删除包含安装目录、公开资产、回滚槽和配置。内置主题保留、当前主题不可删除。管理端本机明暗偏好和站点主题分开。

“部署受控主题”从受信候选策略读取本地 ZIP。新安装保持未激活；严格新版本升级保留既有回滚槽，当前主题升级沿用所有者的原子资产发布。安装和应用均走真实包兼容性及完整性校验。候选为空时明确提示由部署所有者配置候选，界面不伪装远端市场、下载或上传成功。

## 部署策略

由部署所有者配置 `THEME_V2_CANDIDATE_POLICY_FILE` 指向受信 JSON 文件，内容如下。路径仅供服务器读取，不返回浏览器或审计响应。

```json
{
  "candidates": [
    {"id": "reviewed-release", "path": "/opt/theme-candidates/reviewed.zip", "sha256": "替换为64位小写十六进制摘要"}
  ]
}
```

最多 32 个候选；每个压缩文件最多 32 MiB，解压条目、路径、符号链接、文件摘要、静态资源与运行时兼容性继续由 `ThemeV2Package` 验证。部署前复制为本次操作私有且有界的快照，再次校验固定摘要和清单。

原生主题新增持久表 `tx_native_theme_admin_request` 和 `tx_native_theme_deployment`。已有记录时禁止直接回滚删除表，必须保留向前恢复信息。部署意图记录输入摘要、目标公开版本/摘要和原状态修订，不存储包路径、配置或秘密。

## 验证边界

针对测试覆盖插件 CAS、原请求重放、授权撤回、secret 引用保留与域限制、read/domain 模式、真实浏览器 Core 操作链；主题覆盖受控安装、应用、升级资产/回滚槽、切回内置、删除与删除后重放、已生效未完成意图恢复、篡改拒绝及当前授权。

前端覆盖分类、文档转义、配置修订/草稿、生命周期确认、运行查询与变更分流、候选升级确认、未知请求恢复和删除主题后的库存授权恢复。针对测试不是整站桌面/手机/暗色真实浏览器验收，也不证明跨进程崩溃或 MySQL 并发已验收。
