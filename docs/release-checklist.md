## 回滚计划

### 回滚触发条件

- [ ] 错误率 > 5%
- [ ] P95 延迟 > 2s
- [ ] 上游不可用持续 > 1 分钟
- [ ] 安全事件

### 回滚步骤

1. 关闭前端 Gateway feature flag
2. 在代理层移除 `/gateway/v1/*` 映射
3. 重启代理
4. 验证旧 API 可用
5. 停止 Gateway（可选）

### 回滚验证

- [ ] 旧 API `/api/v1/*` 可用
- [ ] 管理后台可用
- [ ] 支付回调正常
- [ ] 节点路由正常
