# Third-Party and Provenance Notes

## API

`api/` derives from Xboard and retains the MIT license supplied in `api/LICENSE`.

## Optional plugins

`integrations/AccessAudit/` is an optional panel-side plugin shipped with TXBoard. It is maintained as a plugin boundary rather than as part of the TXBoard core API.

The TX-Node runtime, its embedded proxy engines, and their dependency notices are maintained independently in the [ANRCM0/TX-Node](https://github.com/ANRCM0/TX-Node) repository and are not part of this source tree.
